```sh
npm install

```

## النسخة العامة

الواجهة والمحتوى المحلي والبحث منشورة على GitHub Pages. المساعد الذكي وتوليد الصوت يحتاجان ربط Gemini عبر خادم آمن ولم يُفعّلا. ملف .env.local لم يُرفع ولا يُضمّن مفتاح API في ملفات المتصفح.

المحتوى القانوني نُقل من المصدر دون تدقيق في صحته أو حداثته. يجب الرجوع للمصادر الرسمية قبل اتخاذ أي قرار.

GitHub Actions يبني وينشر عند تحديث main؛ مصدر Pages هو GitHub Actions.
